# Sample synthetic match (seed 7, 2 × 15 min)

These files were generated by `npm run intel -- --seed 7 --half 15 --out submission/sample-data`. All of it is synthetic: fictional clubs and players, events from the THE 12TH MAN physics simulation, and no real match data. The orchestrator ran with the app's settings, and every decision was settled by the players' own choice.

## `match-7-events.json` – event log (`the12thman.events/v1`)

- `roster`: id, name, number, team, role and squad (`starter` or `bench`) of all 32 players.
- `events`: every match event in order, each with `id`, `tick` (1/60 s), `time` (s) and `type`.
- Event types:
  - `kickoff`
  - `swing`: a player's kick, with its action and, for a pass, the intended receiver
  - `touch`: boot, head, body or hands, with ball speed and position
  - `catch`, `release`
  - `player-contact`
  - `goal`
  - `out`: with the restart that follows
  - `offside`
  - `foul`: with card and reason code
  - `advantage`
  - `restart`, `in-play`
  - `half-time`, `full-time`
  - `moment`, `decision`: the orchestrator
  - `instruction`
  - `substitution`: with the computer coach's reason

## `match-7-intel.json` – match intelligence (`the12thman.intel/v1`)

- `teams`: possession and territory, passes with completion, average distance and difficulty, progressive passes, shots and shots on target, model xG, pressures and pressures won, balls won and lost, fastest shot.
- `players`: touches, passes, shots, xG, distance, top speed, sprints, balls won.
- `shots`: every shot with time, player, model xG, speed, distance, outcome and the event IDs it was derived from.
- `insights`: every explained moment, with
  - `kind`, `clock` and `priority`;
  - `data`: the numbers it rests on;
  - `eventIds`: its source events in the event log;
  - `text`: the wording for **fan** and **analyst** in **English** and **German**.

Every `eventIds` entry refers to an `id` in the event log. The test `src/intel/intel.test.ts` checks this for a full match.
